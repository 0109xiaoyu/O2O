# O2O优惠券个性化投放预测与业务策略分析
> 基于用户、商户、优惠券多维特征的机器学习建模与业务决策支持

## 项目概述

本项目基于O2O平台的历史优惠券领取与消费数据，旨在预测用户领券后15天内是否会到店核销，从而支持精准投放、提升核销率与投放ROI。项目完整覆盖了从探索性分析、数据清洗、特征工程、模型构建到模型评价与业务策略建议的全流程，最终通过决策树与XGBoost分类模型实现预测，并基于特征重要性分析提出可落地的运营策略。

- **任务类型**：二分类预测（核销/未核销）
- **核心目标**：预测用户领券后15天内是否核销，支持精准投放决策
- **技术栈**：Python (Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn)
- **关键成果**：
  - 构建13个用户、商户、优惠券维度特征
  - 决策树准确率96.21%，XGBoost准确率96.88%，F1值72.04%
  - 识别出优惠券流行度、用券间隔、用券率等关键影响因素
  - 提出客群分层、精准投放与商户经营优化建议

## 数据来源与字段说明

数据来自天池O2O优惠券赛题（2016年），包含训练集与测试集。主要字段如下：

| 字段 | 含义 | 建模角色 |
|------|------|----------|
| user_id | 用户ID | 分组键 |
| merchant_id | 商户ID | 分组键 |
| coupon_id | 优惠券ID | 分组键 |
| discount_rate | 折扣率（满减或折扣） | 特征 |
| distance | 用户到门店距离 | 特征 |
| date_received | 领券日期 | 时间变量 |
| date | 消费日期 | 标签来源 |

训练集包含约164.9万条记录，测试集约10万条。正样本（15天内核销）占比约6%，存在类别不平衡。

## 步骤详解

### 01 探索性分析

对原始数据进行多维度探索，了解数据分布与业务特征。

**1.1 描述性统计**

统计训练集与测试集的缺失值、最大值、最小值，发现`coupon_id`、`date`等字段存在大量缺失（业务含义：未领券、未核销）。

**1.2 用户消费行为分析**

- **各月消费次数折线图**：2016年1-6月消费次数呈波动上升趋势，5月达到峰值。
- **领券与领券消费柱状图**：各月领券量远高于领券消费量，说明核销率较低，存在大量领券未用情况。

**1.3 商户投放分析**

- 平台共5452家商户参与发券，绘制发券数量前10名商户柱状图。头部商户（如3381、760等）发券量极大，但核销情况参差不齐。

**1.4 距离分布分析**

- 绘制用户到门店消费距离的饼图：约68.3%的消费发生在距离为0（极近距离），12.0%在距离1，距离越远消费占比越低。
- 持券与未持券消费的距离分布相似，均集中在近距离，说明距离是影响消费的重要因素。

### 02 数据预处理

对原始数据进行清洗与转换，为特征工程和建模做准备。

**2.1 数据清洗**

- 将`null`字符串替换为`NaN`，处理缺失值。
- 统一日期格式，解析`date_received`和`date`为datetime类型。
- 处理`discount_rate`：将满减形式（如"150:20"）转换为折扣率（0.87），保持数值统一。

**2.2 数据变换**

- 构建用户标签：计算消费日期与领券日期的间隔天数，`diff_days <= 15`标记为1（核销），否则为0。
- 剔除未领券的样本（`coupon_id`为空），仅保留有领券记录用于建模。

### 03 特征工程

基于业务逻辑，从用户、商户、优惠券三个维度构建13个特征：

**用户维度**：
- 用券次数、总消费次数、用券率
- 领取未使用次数
- 平均用券间隔

**商户维度**：
- 发券被使用数、被使用率、发券总量
- 未使用数、平均使用间隔

**优惠券维度**：
- 15天内核销数、券使用率

将三组特征与原始数据合并，构建训练集与测试集的特征矩阵。

### 04 构建模型

采用决策树与XGBoost两种分类模型进行预测。

**4.1 决策树模型**

- 参数：`max_leaf_nodes=16, random_state=123`
- 训练并预测测试集，输出预测结果。

**4.2 XGBoost模型**

- 参数：`max_depth=8, learning_rate=0.1, n_estimators=160, objective='binary:logistic'`
- 训练并预测测试集，输出预测结果。

### 05 模型评价

**5.1 评价指标**

| 模型 | 准确率 | 精确率 | 召回率 | F1值 |
|------|--------|--------|--------|------|
| 决策树 | 96.21% | 70.20% | 63.91% | 66.91% |
| XGBoost | 96.88% | 77.81% | 67.06% | 72.04% |

XGBoost模型各项指标均优于决策树，预测效果更好。

**5.2 特征重要性**

绘制XGBoost特征重要性图，结果显示：
- **优惠券流行度**（`coupon_fifteen_used_count`）重要性最高，是影响核销的最关键因素。
- 其次是**领取与使用优惠券间隔**（`user_mean_use_coupon_interval`）和**用户用券率**（`user_use_coupon_rate`）。
- **用户到门店距离**（`distance`）重要性最弱，说明在本数据中距离对核销预测的贡献较小。

## 06 业务应用与策略建议

基于上述分析结果，为O2O平台提供以下可落地的运营策略：

**6.1 客群分层与精准投放**
- 根据用户历史用券率与消费频次，将用户划分为高活跃高用券、高活跃低用券、低活跃高用券、低活跃低用券四类。
- 对高核销概率用户优先推送优惠券，降低无效投放成本；对低潜客群减少投放或仅推送高吸引力券种。

**6.2 商户经营优化**
- 头部商户发券量极大，但核销率参差不齐。建议对高核销率商户倾斜流量资源，对低核销率商户进行联合营销或券种调整。
- 针对发券量前10的商户，可进一步分析其券种与用户匹配度，提升经营效率。

**6.3 优惠券产品优化**
- 特征重要性显示，券的流行度对核销影响最大，而距离影响最弱。建议平台设计“爆款券”提升券本身的吸引力，而不是单纯依赖“附近推送”。
- 通过提高券的传播度与折扣力度，拉动核销率。

**6.4 模型部署与决策闭环**
- 模型输出的0/1分类结果可直接接入营销系统，对预测为1（高核销概率）的用户自动发券，对预测为0的用户不投或改投低门槛券。
- 定期用新数据重新训练模型，形成“数据-模型-策略-反馈”的闭环，持续优化投放ROI。
